Privacy Policy

Effective and last updated: July 22, 2026.

Information we process

Nalarin Ads Studio processes account identifiers, campaign configuration, and performance metrics that an authorized user permits through Google Ads or another advertising provider. We also process the name and email used to authenticate to the application. We do not request or store Google account passwords.

Purpose and use

Provider data is used only to display advertising performance, prepare reports, and perform campaign actions explicitly requested and confirmed by an authorized operator. We do not sell Google user data, use it for independent advertising profiles, or transfer it to data brokers.

Google API Services user data

Nalarin Ads Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google Ads OAuth credentials are used only for the advertising management features described on the application home page.

Security

OAuth access and refresh tokens are encrypted at rest. Application passwords and machine API keys are hashed. Production traffic uses HTTPS. Provider credentials are not exposed to the browser after OAuth, and reporting bots have read-only access with no campaign write routes.

Retention, revocation, and deletion

Connection data is retained while needed to provide the service. Operators can disconnect an account in Nalarin Ads Studio or revoke access in Google Account permissions. To request deletion of account data or OAuth credentials, email the address below. Verified requests are processed within 30 days.

Sharing

Data is shared only with infrastructure providers needed to operate the service or when required by law. Those providers may not use Google user data for independent advertising purposes.
