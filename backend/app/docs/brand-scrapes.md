# Scrape Brand Ads

theLeadRouter — Ad Studio

Open Research → Scrape Brand Ads. Enter a brand name and Facebook Page ID or supported Ads Library URL, then start the scrape. The list shows pending, scraping, completed, or failed status and media counts. Open a completed scrape to inspect its ads.

Downloaded media uses the configured upload storage. A failed scrape can reflect provider rate limits, an inaccessible page, or storage problems. Check the displayed error before retrying. Deleting a scrape removes its stored application records; review the confirmation first.

API group: /api/v1/research. Search the endpoint reference for brand scrapes. These operations use the application's configured research provider and storage; adding a user API key does not configure those services.
